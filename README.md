Cost Calculator for Mess

A simple Python program that calculates the monthly mess expenses for each person based on rent, food, electricity costs, and the number of people living in the mess.

Features

- Calculates total monthly mess expenses
- Divides expenses equally among residents
- Takes rent, food, electricity, and number of people as input
- Simple and beginner-friendly Python program

Technologies Used

- Python

How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Run the Python file:

python Cost-calculator-for-mess.py

4. Enter the requested information.

Example

Input

Enter the mess rent = 3000
Enter the food cost = 3000
Enter the total electricity bill = 200
Enter the number of persons living in the mess = 2

Output

Each person will pay = 3100

Project Purpose

This project was created as a beginner Python project to practice user input, arithmetic operations, variables, and basic programming logic.
